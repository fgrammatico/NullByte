## Noise bands

`getNoiseBand(level)` maps the current `nb_noise` score to a band:

| Band | Range | Primary patrol mob |
|---|---|---|
| CLEAN | 0 – 24 | — (no patrols) |
| WARNING | 25 – 49 | `minecraft:zombie` |
| ALERT | 50 – 74 | `minecraft:vindicator` |
| BREACH | 75 – 99 | `minecraft:ravager` |
| LOCKDOWN | 100 | `minecraft:vindicator` + 1 `minecraft:warden` (boss, on escalation) |

---

## Band escalation effects

`onBandEscalation(from, to)` fires whenever `nb_noise` crosses a band boundary upward.

### Any escalation to ALERT or higher
- Increments `nb_alarms` by 1.
- If `nb_fwall >= 1`: sets `nb_fwall = 0` (firewall exploit auto-patched).

### WARNING
- Spawns 3 zombies (shared across players).
- Chat: `[SENTINEL] Warning threshold reached.`

### ALERT
- Spawns 6 vindicators.
- Sets terminal lock: 10 seconds.
- Chat: `[SENTINEL] ALERT state active. Terminal lockout: 10s.`

### BREACH
- Spawns 12 ravagers.
- Sets terminal lock: 30 seconds.
- Revokes shared permission to `guest` (0).
- Teleports all players to `BOUNDARY.spawnX/Y/Z` in the Overworld.
- Chat: `[SENTINEL] BREACH state. Shared permission revoked.`

### LOCKDOWN
- Spawns 20 mobs: 1 warden (first spawn slot) + 19 vindicators.
- Sets terminal lock: 60 seconds.
- Revokes shared permission to `guest` (0).
- Chat: `[SENTINEL] LOCKDOWN active. Terminal disabled.`

Downward crossing from ALERT or higher back below ALERT:
- Chat: `[SENTINEL] Threat reduced. Re-authentication available.`
- No automatic permission restore; players must re-run `nb:login` and `nb:sudo`.

## Scheduled patrols (tick loop)

`getPatrolIntervalTicks` and `getScheduledPatrolCount` drive periodic spawns while noise stays in a band:

| Band | Interval | Mob count per wave |
|---|---|---|
| CLEAN | — (disabled) | 0 |
| WARNING | every 40 seconds | 3 zombies |
| ALERT | every 20 seconds | 6 vindicators |
| BREACH | every 10 seconds | 12 ravagers |
| LOCKDOWN | every 10 seconds | 20 (vindicators + warden first wave) |

The patrol timer (`lastPatrolTick`) resets on every band escalation.

## Per-command-penalty patrols

`applyCommandPenalty` is called on command failures and some successes. After adding noise it calls `getMisuseSpawnCount(updatedNoise)` and spawns that many mobs immediately:

| Band at time of penalty | Immediate spawn count |
|---|---|
| CLEAN | 0 |
| WARNING | 1 |
| ALERT | 2 |
| BREACH | 3 |
| LOCKDOWN | 4 |

These spawn in addition to any band-escalation spawns triggered by the same noise addition.

## Noise decay (tick loop)

Runs on every game tick via `gameTick()`.

| Condition | Decay rate |
|---|---|
| CLEAN or WARNING, no IDS | −1 per second (every 20 ticks) |
| ALERT, no IDS | −1 per 2 seconds (every 40 ticks) — slower |
| Any band, IDS active (`nb_ids >= 1`) | decay × 2 |
| LOCKDOWN | no decay (frozen) |

IDS doubling stacks with the ALERT slow: at ALERT with IDS active, noise decays −2 per 2 seconds.

## Patrol spawn locations

`spawnMisusePatrols` and `spawnSharedPatrols` both use this priority:

1. `chiseled_stone_bricks` within a 64-block radius, 16 blocks vertical. Sorted nearest-first.
2. Fallback: player-relative offset grid (20 preset offsets). Each position is validated for a solid floor with 2 air blocks above before spawning.

Place `chiseled_stone_bricks` at intended patrol positions in the world to control where mobs appear.

---

## Terminal lock

`nb_locked` counts down by 1 per tick in `gameTick`. While `nb_locked > 0`, any terminal command returns:

```
TERMINAL LOCKED — Xs remaining
```

Lock is set by band escalation (see above). A new escalation only extends the lock if the new duration exceeds the current remaining ticks (`setLockTicks` takes the maximum).

---

## Victory

When `nb_victory >= 1`, `gameTick` skips all noise, patrol, boundary, and lock processing and shows `ROOT ACCESS — HEXCORE OFFLINE` on the action bar for all players.
