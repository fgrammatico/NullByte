# In-Game Sign Style

Exact sign copy is private because it contains puzzle evidence and answers.

## Character voices

- ZERO writes short, dry evaluation messages.
- GHOST leaves informal technical notes and incomplete context.
- SENTINEL reports defensive actions without emotion.
- Corporate signs use neutral policy language.

## Placement rules

- Put required evidence on the main investigation route.
- Keep each sign readable within Minecraft's line limits.
- Split long evidence across nearby signs rather than shrinking the text.
- Use consistent materials for each author so players can identify the source.
- Do not place exact answers beside the control that accepts them.

## Public spoiler policy

Exact credentials, event records, access codes, item mappings, dialogue answers, and ordered sequences must remain in private builder material.
