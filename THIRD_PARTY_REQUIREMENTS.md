# Third-Party Requirements

NullByte depends on the following commercial Minecraft Bedrock add-ons. Import each one separately from an authorized seller or marketplace before opening the world.

| Add-on | Publisher | Required version / note |
|---|---|---|
| Computers add-on | Jigarbov Productions | Use the compatible version you imported for this world; this repository does not pin a marketplace-specific pack ID or version for the add-on itself |
| Security Sandbox | Spectral Studio | Use the compatible version assigned to the current world build |
| Ultimate Blasters | 1.2 | Required version is 1.2 |

The exact pack UUIDs can vary by marketplace copy and installation source. Do not reuse stale IDs from older docs or earlier releases. Match the actual imported add-on copies that are available in the host world.

## Distribution policy

NullByte releases do not contain any of the commercial add-ons. The release ZIP contains only NullByte files, public player documentation, and the world archive. Each host is responsible for obtaining valid copies of the required add-ons.
