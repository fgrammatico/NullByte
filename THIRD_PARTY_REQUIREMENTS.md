# Third-Party Requirements

NullByte depends on two commercial Minecraft Bedrock add-ons. Obtain and import them separately from an authorized seller or marketplace before opening the world.

| Add-on | Required version | Behavior pack ID | Resource pack ID |
|---|---:|---|---|
| Security Sandbox | 1.0.6 | `9cff8ac5-0cde-4bca-8fec-4eb8078ddab3` | `71a7d53f-3bbc-4d03-8c76-76a9cdb1f1f3` |
| Ultimate Blasters | 1.1.7 | `53589f2a-0405-4841-8ccc-8679b605aead` | `dfd76498-33a0-4b3b-9ca5-494734a63c29` |

The version values above match the references stored in the packaged world. A different installed version may cause Minecraft to report a missing or incompatible pack.

## Distribution policy

NullByte releases do not contain either commercial add-on. The release ZIP contains only NullByte files, public player documentation, and the world archive. Each host is responsible for obtaining valid copies of the required add-ons.
