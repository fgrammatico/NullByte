01

The Mission

Context

NullByte is a cooperative hacking puzzle built as a Minecraft Bedrock world. HEXCORE is a rogue automated system that has locked down the network. Players work together to breach it, following evidence left by a former insider called GHOST, and shut it down for good. Every area, puzzle, and mechanic maps to a real cybersecurity concept.

🎯

Objective

Breach HEXCORE's network and gain root access to shut the whole system down. Work through seven security layers, escalate from guest to root, and execute the final exploit before SENTINEL locks you out permanently.

🤝

Multiplayer

One or more players can investigate the same world. Puzzle discoveries, permission, noise, defenses, and victory are shared. Players may join, leave, or die without resetting progress.

🔐

Real Concepts

Every puzzle teaches a security concept: credential handling, log analysis, lateral movement, access-code decoding, firewall rules, and more. No prior knowledge required.

02

The World

3 Areas

The world is divided into three areas, each representing a layer of HEXCORE's network. You start in the Overworld and work your way deeper into the system.

🌿

Overworld

USER SPACE

Corporate offices, server rooms, hardware labs. This is HEXCORE's exposed surface, the part of the network you can reach without special access. Start here. Explore carefully.

🔥

Nether

RESTRICTED SERVICES

Core infrastructure. Internal services. This area is locked behind a firewall. You'll need to find a way through before you can enter.

💜

The End

SYSTEM CORE

The isolated heart of HEXCORE's network. Cold storage. The final encryption layer. This is where the root exploit runs. Shared admin permission required.

03

Shared Permission

4 Levels

The world has one active permission level. It determines which commands are available and which areas can be accessed. Every player begins with the same guest session and observes each escalation.

GUEST

Guest — Where you start

Anonymous access. Basic recon commands only. Cannot use exploits or enter restricted areas.

USER

User — Authenticated local access

Requires credentials found in the world. Unlocks exploit commands and stealth operations.

ADMIN

Admin — Privileged access

Requires solving a privileged access-code challenge in the Nether. Enables higher-level terminal operations.

ROOT

Root — Win condition

Full system access. Achieved by executing the root exploit from the System Core. Game over, you win.

05

Noise & Detection

Stay Under the Radar

Everything you do generates noise. The higher your threat level, the more aggressive HEXCORE's defense response. Noise decays passively over time, but it accumulates fast if you're careless.

🟢

Silent

No active defenses. Normal gameplay. This is where you want to be.

🟡

Detected

The IDS (Intrusion Detection System, HEXCORE's automated threat monitor) has flagged your activity. Defense patrols activate. Move carefully.

🟠

Alert

Incident response is active, and HEXCORE's security team is reacting in real time. Defenses may lock the terminal, patch temporary access, or revoke the active permission level. Completed puzzle discoveries remain recorded.

🔴

Lockdown

Full defensive response. Permissions revoked, you lose your current access level. The terminal goes dark. You must recover.

Tip
Some commands are quieter than others. Failed commands always cost more noise than successful ones. Finding the right tool for the right moment is part of the challenge.
06

Getting Started

First Steps

You just joined. HEXCORE is watching. You have no credentials, no tools, and a lot of ground to cover. Here’s where to start.

1

Open your hacking device

Press T to open the chat (on mobile, tap the chat icon). Type /nb:menu and hit Enter. That's your toolkit. The chat is your terminal, and it is always with you.

2

Read what /nb:menu tells you

It lists every command you can run right now. At the start that's just the basics. As you find things in the world, new commands appear here automatically.

3

Explore the Overworld

The world is full of clues. Read every sign. Talk to every NPC. Interact with things. The environment tells you where to go next, nothing is random decoration.

4

Watch the bar at the bottom of your screen

It shows the shared noise score and threat status. Use /nb:whoami to check the active permission level. If noise climbs, slow down.

5

Solve, unlock, go deeper

Each puzzle you solve gives you something: a new command, access to a new area, or a higher access level. Work your way from GUEST all the way to ROOT. That's the win.
