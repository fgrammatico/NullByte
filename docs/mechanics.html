01

Addon Architecture

Core Systems

All core logic is implemented using the Minecraft Bedrock Script API (@minecraft/server v2.7.0). The behavior pack is compiled from TypeScript (packs/src/main.ts) and distributed as a .mcaddon file for locally hosted worlds. Realm deployment is not supported.

Shared Multiplayer State
Progression, permission, noise, defenses, gates, and victory use the scoreboard participant NB_GLOBAL. Players may join, leave, die, or rejoin without resetting the world. Individual points are deferred and will not control gameplay.
Installing Addons
Open the .mcaddon file on the host machine, import both packs into Minecraft Bedrock, and activate them on the local world. Other players join the hosted world through supported local multiplayer.
Chat is the Terminal
There are no terminal blocks in the world. The Minecraft chat is the player's hacking device, always with them, always connected. Players type /nb:<command> directly. No ActionForm UI, no block-interact events. This simplifies both world building and the script significantly.

Defense Counter-Play
Exploits can be auto-patched by the defense system when noise reaches ALERT (50+). If you exploit the firewall and then trigger ALERT, the IR team patches it; your exploit becomes useless. Players must manage noise carefully or use stealth commands to stay below thresholds.
03

Permission Escalation Tree

4 Levels

The world has one shared permission level. Login and sudo escalate it for everyone currently connected or joining later. BREACH and LOCKDOWN revoke permission to guest but never erase completed puzzle flags, so recovery only requires re-running login and sudo.

GUEST

Guest: Anonymous Session

Starting permission. Menu, identity, and status are always available. Recon and login appear after credentials are discovered.

→ Always: menu, whoami, status · After P01: scan, ls, cat, login
USER

User: Shared Authenticated Session

Gained via login admin hexc0re2049 after finding the credential vault. Unlocks exploit commands and stealth operations.

→ Unlocks: exploit firewall, exploit ids, patch_covers, sudo
ADMIN

Admin: Shared Privileged Session

Gained via sudo after decoding the Nether access byte. Grants access to encryption exploits and the patrol kill command.

→ Unlocks: exploit encryption, kill_patrol, exploit root (after encryption and Port Knock)
ROOT

Root: Full System Access

The win condition. Gained only by executing exploit root in the System Core after encryption is broken and Port Knock is complete. Victory persists and all defenses stop.

→ Game Over (Victory): all defenses disabled, victory sequence plays

05

Chat Interface

Implementation

The game chat is the terminal. No terminal blocks, no ActionForm UI, no block-interact events needed. Players type /nb:<command> directly in chat. The Script API custom command registry handles execution, checks preconditions, applies noise, and returns output as chat messages.

Lore Framing
In the game narrative, the chat is the player's portable hacking device, always on them, always connected. This framing means no physical terminal placement is required in the world.
Command Prefix
All commands use the nb: namespace prefix. Players type /nb:menu, /nb:scan, etc. The slash is added automatically by Minecraft when opening the chat command bar (T or /).

Implementation Notes

Commands are registered in system.beforeEvents.startup via CustomCommandRegistry. Handlers read NB_GLOBAL, enforce preconditions, apply shared noise, and return output to the operator. The action bar shows shared noise and threat. Puzzle flags are immutable; temporary permission and exploit states use separate objectives.

Full Exploit Chain

Complete Playthrough Path

This is one complete path from guest to root. Players may discover steps in different orders or take alternate routes (e.g., disabling IDS before exploiting the firewall for less noise penalty).

1

Credential Discovery

Follow the lobby briefing and GHOST note to the Credential Vault. Read the auth.log backup, then press the discovery button to set nb_p01. The shared flag capture reduces noise by 3.

2

Reconnaissance

Run ls, cat auth.log, cat config, and scan. Solve the SSH Log Triage (nb_p03) and Firewall Rules Console (nb_p05). Each first flag capture reduces shared noise by 3.

3

Authentication: login

Run login admin hexc0re2049. The script validates both values before shared permission changes from guest → user. A successful first login adds 10 noise.

4

Disable IDS (Optional but Recommended): exploit ids

With nb_p05, run exploit ids before exploiting the firewall. This adds 12 noise and doubles passive noise decay for the rest of the session.

5

Firewall Bypass: exploit firewall

With nb_p03 set and nb_fwall = 0, run exploit firewall. This adds 15 noise and sets nb_fwall = 1. If noise reaches ALERT while the firewall is bypassed, the defense system resets nb_fwall to 0.

6

Navigate to Nether: Restricted Services

With the firewall bypass active, travel through the Nether portal. Decode the recovered access byte at the Binary Access-Code Decoder to set nb_p04. The puzzle capture reduces shared noise by 3.

7

Privilege Escalation: sudo

Run sudo. With nb_p04 set, shared permission changes from user → admin and adds 25 noise. This exposes exploit encryption and kill_patrol.

8

Lateral Movement & End Access

Correlate ticket 4344, host ETH2-GW, and the 04:30 maintenance window. Use that evidence to set nb_p02 and open the End portal gate.

9

Assemble the Key and Knock Sequence

Route the Echo Shard, Amethyst Shard, and Prismarine Crystals through their filtered receivers to set nb_p06. Complete the shared knock sequence 1337 → 22 → 443 to set nb_p07. Wrong knocks reset the sequence and add 2 noise.

10

⭐ Break Encryption and Execute Root

With nb_p06, run exploit encryption to set nb_enc=1 and add 20 noise. From the End, with nb_p07 also set, run exploit root. Root adds 50 noise, persists victory, clears lockout, and stops defenses.

Puzzles by Biome

7 Puzzles Across 3 Areas

Each area contains puzzles that teach a cybersecurity concept. Puzzles use command blocks, redstone, NPC dialogue, or script events. Completion sets an immutable flag on NB_GLOBAL. The first capture of each flag reduces shared noise by 3. For zone atmosphere and story context, see The World ↗ on the main page.

Overworld

USER SPACE
1
Credential Vault

Find the auth.log backup in a concealed server-room vault. It contains the exact username and password. Register the discovery, then authenticate through chat.

→ Sets: nb_p01 (unlocks nb:login)
Concept: Default Credentials / Credential Harvesting
2
SSH Log Triage

Read the SSH log from the night of the incident. Report the first event proving that a disabled account was reused from an external address. Wrong reports add noise.

→ Sets: nb_p03 (unlocks nb:exploit firewall)
Concept: Log Analysis / Anomaly Detection
3
Firewall Rules Console

8 levers labeled with port numbers. Hint: "Allow Web Traffic Only". Set ports 80 and 443 ON, all others OFF. Redstone AND gate detects correct state.

→ Sets: nb_p05 (unlocks nb:exploit ids)
Concept: Firewall Rules / Port Management

Nether

RESTRICTED SERVICES
4
Binary Access-Code Decoder

8 levers are labeled with bit values from 128 to 1. The recovered byte is 01000001, which is decimal 65 and ASCII A. Set levers 64 and 1 ON, all others OFF. The AND gate detects the correct state.

→ Sets: nb_p04 (unlocks nb:sudo)
Concept: Binary Place Values / ASCII
5
Route Access Request

Submit four evidence fields gathered across both dimensions: ticket 4344, host ETH2-GW, maintenance window 04:30, and approver ZERO. Wrong fields add noise. The correct submission opens the End portal gate.

→ Sets: nb_p02 (opens End portal gate)
Concept: Social Engineering / Evidence Correlation
💜

The End

SYSTEM CORE
6
Encryption Key Assembly

Recover an Echo Shard, Amethyst Shard, and Prismarine Crystals from separate End islands. Route each through its matching hopper item filter. Three latched outputs complete the vault.

→ Sets: nb_p06 (unlocks nb:exploit encryption)
Concept: Key Management / Cold Storage
7
Port Knock Sequence

Five pressure plates emit nb:knock script events. Correct order: 1337 → 22 → 443. Any wrong port resets shared nb_knock progress and adds 2 noise.

→ Sets: nb_p07 (enables nb:exploit root)
Concept: Port Knocking / Access Control
